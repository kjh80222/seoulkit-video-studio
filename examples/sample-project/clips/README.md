# clips/

Approved Stage 3 video clips go here, named `shot_{beat}{shot_letter}_flow.mp4`
(e.g. `shot_1a_flow.mp4`). Not checked into git — see `.gitignore`.

`clip_manifest.json` (checked in) is the real content of this example: it's
owned by Stage 3 QC and read-only for Stage 4/5 (Stage 5 spec ch. 02, ch. 24).
